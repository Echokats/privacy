Privacy Policy

Application: Echokats Content Pipeline
Last updated: May 2026

Overview

This application is a personal content automation tool used solely by its owner to post AI-generated videos to a personal TikTok account. It does not collect, store, or share data from any third party.

Data Collection

This application does not collect any personal data from users. The application is not publicly accessible and has no user-facing interface.

TikTok API Usage

This application uses the TikTok Content Posting API exclusively to post video content to a single TikTok account owned and operated by the application owner. No TikTok user data is accessed, stored, or transmitted beyond what is required to authenticate and post content.

Data Storage

No personal data is stored by this application. API credentials are stored locally on the owner's device and are not shared with any third party.

Third Party Services

This application makes use of the following third party APIs:

  • TikTok Content Posting API
  • Segmind API (AI video generation)
  • Anthropic API (content generation)
  • Cloudflare R2 (temporary video file storage)

Each of these services operates under their own privacy policies.
